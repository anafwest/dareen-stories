# قصص دارين

موقع قصص عربي بسيط وأنيق، من إعداد **ثانوية بدر الأولى للبنات – وزارة التربية والتعليم**.

- الرابط المباشر: <https://anafwest.github.io/dareen-stories/>

## المحتوى

200 قصة موزّعة على ستة أقسام:

| القسم | العدد |
|---|---|
| قصص من كتب | 29 |
| روايات | 40 |
| قصص الأنبياء | 27 |
| حكم | 40 |
| آداب | 39 |
| شعر | 25 |

تم جمع القصص من مصادر مختلفة.

## التقنية

موقع ثابت بالكامل (HTML + CSS + JavaScript) دون أي خادم أو قاعدة بيانات.

```
index.html          صفحة الأقسام والبطاقات
story.html          صفحة قراءة القصة (story.html?id=...)
css/style.css       التصميم المتجاوب
js/data.js          بيانات القصص
js/app.js           بناء البطاقات وصفحة القصة
assets/img/covers/  غلاف SVG لكل قصة
assets/img/flag.svg علم المملكة
```

## النشر

يُنشر الموقع عبر GitHub Pages من الفرع `main` (المجلد الجذر).
