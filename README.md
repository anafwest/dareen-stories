# دارين | قصص قصيرة للمرحلة الثانوية

صفحة ويب حديثة ومخصصة لعرض قصص قصيرة للمرحلة الثانوية، مصممة خصيصًا لتفتح مباشرةً عند مسح رمز QR عبر الهاتف.

## مميزات الصفحة

- تصميم عصري داكن يجذب عين القارئ
- واجهة عربية بالكامل ومتجاوبة تمامًا مع الجوال والتابلت
- قصص واقعية ذات طابع تربوي تناسب طلاب المرحلة الثانوية
- صور توضيحية جذابة لكل قصة
- عرض مميز للقصة كاملة مع العبرة المستفادة واقتباس مختصر
- خفيفة جداً، تعمل بدون قاعدة بيانات
- جاهزة للرفع مباشرة على أي استضافة مجانية

## القصص المتوفرة حالياً

1. الوقت كالسيف
2. البذرة والأمل
3. القميص الذي غيّر كل شيء
4. شجرة العطاء
5. طريق مختلف
6. النافذة

## طريقة الاستخدام

1. ضع جميع الملفات والمجلدات داخل مجلد واحد
2. ارفع المجلد إلى إحدى المواقع المجانية:
   - [Netlify Drop](https://app.netlify.com/drop)
   - [Cloudflare Pages](https://pages.cloudflare.com)
   - [GitHub Pages](https://pages.github.com)
3. انسخ رابط الموقع الناتج، مثل:
   ```text
   https://dareen-stories.netlify.app
   ```
4. حول الرابط إلى رمز QR باستخدام أحد المواقع:
   - [goqr.me](https://goqr.me)
   - [qrcode-monkey.com](https://ar.qrcode-monkey.com)
5. اطبع رمز QR ووزّعه على الطلاب ليمسحوه ويقرأوا القصص مباشرةً

## إضافة قصة جديدة

1. أضف صورة SVG جديدة داخل مجلد `assets/img/` أو استخدم صورة جاهزة.
2. افتح ملف `js/data.js` وأضف كائنًا جديدًا داخل مصفوفة `STORIES` بنفس تنسيق القصص الموجودة.
3. احفظ الملف وسيظهر تلقائياً في الصفحة الرئيسية.

## معاينة محلية

يمكنك فتح `index.html` مباشرةً في المتصفح، أو تشغيل سيرفر محلي لعرض أفضل مثل `Live Server` في VS Code.
